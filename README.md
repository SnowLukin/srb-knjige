# Knjige — книги сербского предузетника

Приложение для macOS, чтобы самому вести учёт ИП в Сербии на «книгах» с личной зарплатой (preduzetnik koji vodi poslovne knjige, lična zarada). Рассчитано на один сценарий: IT-услуги иностранному клиенту, оплата через Deel или напрямую в евро.

Что умеет:

- **Инвойсы** с нумерацией по порядку и PDF на сербском и английском.
- **Поступления**: курс НБС на дату, комиссия Deel или банка, курсовые разницы считаются сами.
- **Конвертации** евро в динары, с курсовым доходом или расходом относительно курса НБС.
- **Расходы** с прикреплёнными счетами.
- **Личная зарплата**: расчёт взносов и налога, калькулятор «хочу на руки N», заполнение минимальной зарплатой.
- **Налоги**: прогноз на год, ежемесячный аванс налога на прибыль по PPDG-1S, оценка годового налога на доход.
- **Календарь сроков**: PPP-PD, авансы, APR, PPDG-1S, годовой налог, продление ВНЖ.
- **Журнал двойной записи** и оборотно-сальдовая ведомость строятся автоматически из операций.
- **Импорт скриншотов и PDF**: текст распознаётся встроенным в macOS Vision, без интернета. Находятся суммы, валюты, даты и IBAN, и из них можно сразу создать поступление, расход или конвертацию.
- **Годовая сводка** для деклараций и экспорт в CSV для Numbers или Excel.
- Курсы НБС загружаются автоматически, а если сервис недоступен, их можно ввести вручную.

Данные хранятся только на этом Маке: `~/Library/Application Support/Knjige` (data.json, вложения и ежедневные резервные копии).

## Сборка

Нужны macOS 14+ и Xcode 15+ (или Command Line Tools со Swift 5.9+).

```bash
git clone https://github.com/SnowLukin/srb-knjige.git
cd srb-knjige
./scripts/build_app.sh --install   # соберёт Knjige.app и положит в /Applications
```

Другие варианты:

```bash
swift run Knjige        # запустить без сборки .app
swift test              # тесты расчётов
open Package.swift      # открыть в Xcode
```

## С чего начать

1. **Настройки → Профиль ИП**: название из APR, ПИБ, МБ, адрес, банк, IBAN, дата регистрации.
2. **Настройки → Клиенты**: тот, кому ты выставляешь инвойсы.
3. **Настройки → Авансовая декларация**: прогноз на год (тот же, что подаёшь в PPDG-1S).
4. Каждый месяц: инвойс → поступление (скрин из Deel в «Импорт», ⇧⌘V) → зарплата → аванс налога.

Подробности по шагам — в разделе «Как это работает» внутри приложения.

## Что нужно проверить один раз

- **Коды счетов** в «Настройках → План счетов». Стандартные коды уже стоят, но счета, помеченные «?», нужно сверить с контным планом для предпринимателей. Это влияет только на журнал и финансовый отчёт, на налоги — нет.
- **Налоговые параметры** на 2026 год взяты из открытых источников: минимальная база 51 297 RSD, необлагаемая часть 34 221 RSD, средняя годовая зарплата 1 813 032 RSD. Каждый январь добавляй новый год.

## Чего приложение не делает

- Не подаёт декларации. PPP-PD, PPDG-1S и PPDG-2R подаются в ePorezi, финансовый отчёт — в APR. Приложение даёт цифры для них.
- Не учитывает государственные праздники в сроках.
- Не амортизирует дорогую технику: она списывается сразу.
- Не ведёт НДС. Если появятся сербские клиенты и оборот с ними приблизится к 8 млн RSD, приложение предупредит.

Это помощник для учёта, а не официальный бухгалтерский софт.
